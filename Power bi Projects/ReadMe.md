Financial Performance & Sales Analytics Dashboard

 Project Overview
An interactive financial sales dashboard built using Microsoft Power BI to analyse business performance and generate meaningful insights.

 Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

 Key Performance Indicators
- Total Sales
- Total Profit
- Gross Sales
- Total Discounts
- Profit Margin

 Dashboard Features
- Country-wise Sales Analysis
- Product-wise Profit Analysis
- Monthly Sales Trend
- Interactive Data Filtering
- Financial Performance Monitoring

 Data Preparation
- Imported the Microsoft Financial Sample dataset.
- Performed data profiling using Power Query.
- Created DAX measures for business calculations.
- Built interactive charts and KPI cards.

 Business Insights
- Compare sales performance across countries.
- Identify profitable products.
- Analyse monthly sales trends.
- Understand the relationship between discounts and profitability.
